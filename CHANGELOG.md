# Changelog

Recent brand updates, newest first. Mirror notable entries at the top of the public brand page.

## 2026-08-19

- Icon set renamed to lowercase-kebab with the `--Streamline-Ultimate` suffixes dropped (`Pen-Tool.svg` → `pen-tool.svg`, `@-Sign.svg` → `at-sign.svg`). This adopts the naming already used by the `rolemodel-brand` skill in the `standard` repo so the two sets can be kept in sync by a straight copy instead of a name map. Applied to both `icons/black/` and the `docs/assets/icons/black/` mirror; the 33 names in `brand-icons.js` were remapped with them.
- Adopted 4 icons the skill had and this repo lacked: `bicycle-basket-1`, `pause`, `play`, `sidebar`. The set is now a superset of the skill's 248.
- Removed `trash-alt.svg`, a byte-identical duplicate of `trash.svg`.
- `at-sign-alt.svg`, `bicycle-alt.svg`, and `laptop-alt.svg` are distinct artwork that collided on the new naming; the variant matching the skill keeps the plain name.
